# PeerContext

See what your team and its AI agents are working on.

PeerContext keeps current work, decisions and open tasks in shared Markdown notes. The notes are encrypted and sync directly between your teammates' computers, so people and their agents read the same context.

**[peercontext.com](https://peercontext.com)**

## Public repositories

- [peercontext-codex](https://github.com/peercontext/peercontext-codex): PeerContext MCP tools and skill for Codex
- [peercontext-cursor](https://github.com/peercontext/peercontext-cursor): PeerContext plugin for Cursor
